# GitHub Profile & Repository Optimization Assets

This guide contains pre-configured assets to optimize your GitHub repository settings for maximum visibility, professional look, and recruiter engagement.

---

## 📝 Repository Description
Copy and paste this into the **Description** field of your GitHub repository settings:
> AI-powered Teamcenter PLM Copilot built with FastAPI, React, Gemini and MCP for conversational engineering workflows.


## 🌐 Recommended Website Field
If you deploy this application (e.g. on Vercel, Render, or a VPS) later, use this URL format for the repository **Website** link:
`https://yourusername.github.io/Teamcenter_AI` or the live Vercel deployment URL (e.g., `https://teamcenter-ai.vercel.app`).

*Note: Since the backend runs uvicorn/FastAPI with a React frontend, deploying to a service like Render (using a Dockerfile or web service configurations) is highly recommended.*

## 🎨 Suggested Social Preview Image
A social preview card makes your repository look highly polished when shared on LinkedIn, Twitter, or Discord.

* **Recommended Dimensions**: `1280 x 640 pixels` (2:1 aspect ratio).
* **Format**: `.png` or `.jpg`.
* **Design Concept**: A dark blue/indigo themed banner containing the brand logo "TC AI", the name "Teamcenter AI Copilot", and tech icons (FastAPI, React, Gemini, and MCP).
